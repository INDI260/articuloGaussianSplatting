# Articulo Gaussian Splatting

Un artículo que presenta una revisión de la técnica de esparcimiento gaussiano 3D (3DGS) como método de reconstrucción y renderización de escenas tridimensionales fotorrealistas. Se explora el funcionamiento de 3DGS y sus aplicaciones en plataformas comerciales como Meta Horizon Hyperscape y BRINK Traveler. Además, se identifican las principales limitaciones incluyendo requisitos de escenas estáticas, desafíos en la extracción de geometría, y obstáculos para su integración en aplicaciones interactivas y dinámicas.
